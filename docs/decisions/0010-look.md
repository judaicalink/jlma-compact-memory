# 0010 Look and behaviour: the platform kit, server-rendered pages, little JavaScript

Status: accepted (made autonomously 2026-10-14, to be reviewed with Kai) · Date: 2026-10-14

## Decision

- Every page: `/kit/1/jl.css`, the platform bar (SSI include right after `<body>`), then `/compact-memory/static/cm.css`
  (prefix `cm-`) with its own colours for marks and entity classes, light and dark through `prefers-color-scheme` like
  the kit. A second bar names the showcase (start, search, journals, dashboard, quick search).
- Pages are rendered on the server; charts of pages per year are HTML bars (crisp at any width, each bar a link to
  that year). JavaScript only for the entity autocomplete, opening the filters on wide screens, sorting and filtering
  the journal table, and the dashboard. Static files carry a content hash in their URL.
- Everything a visitor typed is HTML-escaped (nginx runs SSI on these pages); the JSON of the autocomplete escapes `<`.
- On phones the search filters fold into one "Filters" disclosure above the results.

Compact Memory in the graph

The pages, issues and journals are records of the JudaicaLink graph (dataset compact-memory). In 2021, TagMe linked mentions on the pages to entities (cm-tagme); each entity is represented by an entity page. Every number here is a SPARQL query on the platform's endpoint: follow “query” to run it.
